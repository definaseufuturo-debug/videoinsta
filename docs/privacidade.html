Política de Privacidade — videoinsta

Última atualização: 28 de outubro de 2026.

O videoinsta é uma ferramenta de uso próprio, operada por Jonas, que publica vídeos produzidos por ele nos canais dele.

Dados acessados

A ferramenta usa a API do YouTube apenas para enviar vídeos ao canal do próprio operador, com a permissão youtube.upload. Ela não lê, coleta, armazena nem compartilha dados de outros usuários.

Armazenamento

As credenciais de acesso ficam guardadas como segredos criptografados no GitHub Actions e são usadas somente para os envios.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google e os Termos de Serviço do YouTube.
